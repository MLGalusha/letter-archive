# Letter Archive

A web application for preserving and exploring historical personal letters. The platform allows users to browse digitized letters, view transcriptions, and explore metadata like dates, locations, and correspondents.

## Overview

Letter Archive makes historical correspondence accessible by:

- Displaying high-quality scans of original letters
- Providing searchable transcriptions
- Extracting and organizing metadata (sender, recipient, date, location)
- Categorizing letters by themes and topics

## Features

**Public Site**

- Browse archive of published letters
- Search by sender, recipient, location, or content
- Filter by date range and verification status
- View letter images with zoom and pan controls
- Read AI-generated transcriptions

**Admin Panel**

- Upload new letter images
- Review AI-extracted transcriptions and metadata
- Edit and verify letter content
- Publish, hide, or delete letters

## Tech Stack

**Frontend**: React, TypeScript, Vite, React Router

**Backend**: Node.js, Express, PostgreSQL, Google Cloud Platform (planned)

**AI Pipeline**: OpenAI GPT-5.2 for transcription and metadata extraction (planned)

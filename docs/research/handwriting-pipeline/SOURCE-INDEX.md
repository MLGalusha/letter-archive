## Acting-agent evidence boundary

Acting agents may see the current source, bound software proposals, Clean/High Recall
ink views, prompt, legal tool schema, and deterministic receipts. Human ground
truth, hidden prior answer decisions, and evaluation-only review conclusions
must remain outside the acting packet. They may be used only after a frozen run
for evaluation.
